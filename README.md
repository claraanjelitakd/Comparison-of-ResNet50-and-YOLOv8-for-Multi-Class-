# Comparison-of-ResNet50-and-YOLOv8-for-Multi-Class-
Comparison of ResNet50 and YOLOv8 for Multi-Class Brain Tumor Classification on MRI Images
This study aims to compare the performance of ResNet50 and YOLOv8 for multi-class brain tumor classification using MRI images. The classification consists of four categories: Glioma, Meningioma, Pituitary, and No Tumor. ResNet50 is utilized as a deep learning image classification model, while YOLOv8 is implemented as an object detection model capable of performing both classification and tumor localization using bounding boxes.
The dataset is divided into training and testing sets using an 80:20 ratio. Model performance is evaluated using Accuracy, Precision, Recall, F1-Score, Specificity, and ROC-AUC metrics. In addition to quantitative evaluation, visual prediction analysis is also performed to compare the tumor detection capability of each model.
The experimental results indicate that YOLOv8 achieves higher classification performance than ResNet50 while also providing tumor localization capability, making it more effective for MRI-based brain tumor analysis.
Data Input: https://www.kaggle.com/datasets/ahmedsorour1/mri-for-brain-tumor-with-bounding-boxes/data
